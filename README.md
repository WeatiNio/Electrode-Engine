# Electrode Engine

A basic game engine written in Python made for a school project

## Features

- 2D game object system
- Input system
- IUD cylce - (Input, Update, Draw)

## Requirements

- Python 3.x
- pygame-ce

## Usage

Run:

`python3 main.py`

in the project root

## Disclaimer

Electrode Engine is a small game engine designed primarily as a learning and development project. It is not intended to compete with established game engines and may contain unfinished or experimental features
